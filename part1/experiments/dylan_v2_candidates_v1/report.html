Part 1 · four fixed standalone candidates · three supplied fixed blends · anchored control

How do Dylan’s new models score?

None improves on anchored under our current benchmark. All four standalone candidates and all three blends score lower on Train157 CV, Pooled235 CV, original validation and chronology. Several do score higher on Dylan’s J, because they improve his chronological test while giving up random-CV performance. That is a difference in evaluation setup and model behavior, not an observed Kaggle gain.

Supplementary protocol · Paired repeat results · Paired intervals · Source-builder verification

Why the fitting rules need explicit labels

The native runs use Dylan’s unchanged model source. By default, label-free preprocessing and graphs can use all 1,561 rows, including held-out and actual Kaggle test features. SLD estimates the target label frequencies from the query batch. Anchored retains its original inductive access, matching Dylan’s supplied comparison. Therefore his native table does not give every model the same feature access.

The strict table uses the same classifier and head settings, but enforces the repository’s fitting boundaries:

  • Each case contains only eligible fitting rows plus its query rows. Test rows and excluded validation-source rows are absent. Query labels are masked before fitting.
  • Scaling, PCA, clustering, graph nodes and pseudo-labels use only the saved fitting populations. Group-matching masked rows are purged in grouped CV and chronology; chronology keeps only earlier-year fitting rows.
  • Temperature calibration refits the complete uncalibrated pipeline within grouped inner folds. The source instead keeps pseudo-labels fixed while cross-validating only the final classifier.
  • Correct & Smooth residuals use grouped inner folds with freshly fitted preprocessing. Synthetic kNN training features leave out the whole embedding group, including masked duplicates.
  • Cand2’s soft K-means feature scale uses only fitting rows. The source’s scale uses a median over every global row.
  • SLD estimates its target frequencies on the eligible masked training pool, following Dylan’s inductive convention. It does not adapt to the query batch.

These are versioned evaluation adapters, not claims that the original submitted CSVs had these boundaries. Because the tables differ in splits, population sizes, feature access and inner fitting rules, the change between tables cannot be attributed to one factor alone. Native transductive behavior may be useful in a separately authorized setting; it has not beaten anchored under our current contract.

How new are the ideas?

The fixed combinations and the Correct & Smooth implementation are concrete additions worth measuring. LDA, neighbors, clustering, ensembling, prior adjustment and expected-F1 decoding are not all new to this workspace: earlier New Directions studies already include expected-F1 compositional decoding and source-prior corrections. Those older attempts used different recipes and comparators, so this run supplies the direct comparison with the current anchored leader.

What these results establish

Keep anchored as the current choice. The new models are useful alternatives and diagnostic controls, but none earns promotion on our benchmark. Their better native J scores are real, reproducible results under Dylan’s setup; they are not recorded Kaggle results. No candidate or blend has a recorded Kaggle score in our ledger, and this study generated no new submission.

The primary comparison uses one inner seed, 0, matching Dylan’s evaluation harness; the supplementary comparison uses the final builder’s five-seed average. Both were evaluated on the saved benchmark populations; existing final candidate CSVs were not regenerated. The original scored anchored artifact remains 0.89636; no local score here replaces that recorded Kaggle number.

Verification and replay

All 1,104 prediction sets were independently rescored, including each expected-F1 decoder and fixed blend. Anchored exactly reproduced the retained reference predictions in all 138 contexts. All 40 protected hashes passed. The strict run recorded 66,535 nested boundary checks with zero group overlaps.

The supplementary five-seed results add another 1,104 independently rescored prediction sets, with reused anchored controls and 332,675 strict nested boundary checks. Its frozen inputs also passed verification.

Additional fresh-fit probes changed held-out labels, changed one query embedding, and changed inner-calibration held-out labels. The relevant predictions and fitted temperatures remained identical where independence was required. See boundary checks and verification results.
