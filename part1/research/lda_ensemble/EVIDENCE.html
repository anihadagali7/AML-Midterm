Verify and evaluate

From the repository root, run these commands. The latter two need the recorded ML environment. None fits a model.

python3 part1/research/consolidation_v1/verify.py
python part1/research/consolidation_v1/verify_leaders.py
python part1/current_leaders_local.py verify

The first checks retained files and shared data. The second independently rescores retained LDA/reference arrays. The third verifies the shared comparison, including the anchored model.

Rerun a saved experiment

The replay wrapper checks retained source and data hashes, copies the recipe into a new directory, uses the original saved folds and fitting functions, and regenerates earlier candidate predictions when a later experiment needs them. Historical hashes of discarded outputs are explicitly marked omitted. Frozen source and recipes are unchanged.

python part1/research/consolidation_v1/reproduce.py feature_gap_cv_v1 \
  --block eligibility_structure --stage train3 --output /tmp/feature-replay

python part1/research/consolidation_v1/reproduce.py ani_lda_revision_cv_v1 \
  --block revision_full --stage train3 --output /tmp/lda-replay

Use block names from each study's registry.json. Stages are train3, train5, pooled3 and pooled5; together they cover eight repeats in both pools. --check verifies inputs/imports without fitting. The three historical failed/partial versions remain documented; use their corrected versions for replay. The direct Ani comparison runs its complete set of fixed recipes and needs no --block.

The original ML dependencies are in requirements-lock.txt and environment.json. Main Part 1 data is shared through local links, not copied. Historical runners and full-audit commands may expect discarded files; use this wrapper for CV reruns. Supplementary model functions, fixed window plans and summary scores remain available for a new versioned study.

The full shared-comparison replay remains available as python part1/current_leaders_local.py replay --output NEW_DIRECTORY.
