What is held equal

Inductive: both pipelines fit only eligible training gold and original masked rows, with held embedding groups purged. Query inputs enter prediction only. This reproduces the earlier Ani control and current LDA ensemble exactly while freshly refitting the tri-training/SVM partners.

Target inputs: both pipelines additionally receive only the current held-out batch with every label erased. Scaling, PCA, GMM, pseudo-labeling and all ensemble partners use that same permitted input pool. This models original Ani's final submission access, in which target rows can receive pseudo-labels. It is separately labeled and is not inductive generalization. Chronological targets are visible as unlabeled inputs only in this arm.

The original notebook's historical CV used globally fitted transforms, different KFold assignments and actual Kaggle test inputs. Those historical CV results are not used here. The shared local experiment uses each fold's target batch; actual Kaggle test data is never loaded. Its smaller target batches need not reproduce a final 312-row transductive fit.
