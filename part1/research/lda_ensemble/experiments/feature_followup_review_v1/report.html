What this changes

Retesting previously rejected fields under grouped CV was worthwhile: several initially promising effects disappeared on confirmation, and matched controls showed that much of the gold-head gain came from the training change rather than the added feature. Raw-drug subwords, supervised criteria terms, pathway granularity and molecular fingerprints now have explicit evidence under the stronger models. These bounded encodings do not exhaust all uses of those fields.

The native pseudo-label teacher cannot generate multiple positives with its probability normalization, confidence .8 and label cutoff .3. Removing that restriction did not improve the ensemble reliably; it is not established as the cause of the performance gap. Other still concentrates the error budget. Context, nearest-label geometry, metadata and sample-F1-weighted corrections did not solve it in these tests.

The final targeted study also tested molecular fingerprints, criteria terms, raw-drug fragments and protein targets as neighbor-retrieval features, using matched embedding-only controls. Its full results are linked above. Further work should be justified by a new representation or measurable complementary signal. These results do not support another threshold or blend search on the same predictions, or combining several unconfirmed features and calling the result a discovery.

Verification and retained failures

Independent rescoring checked 2,762 complete-OOF repeat records, 13,810 fold prediction arrays and 124 supplementary records. 720 outer-fold contexts checked row coverage, group purges, original-control parity and protected hashes. These are development repeats over reused data, not independent datasets.

Three failed versions remain preserved: the initial utility test rejected valid zero-utility examples; its next version stopped on optimizer line-search failure; the first selected-text version mishandled bracketed isotope notation in raw drug names. Corrected versions reran their tests; no failed fold was dropped. All completed versions passed verification.

Only supplied Part 1 files were used. No Part 2 phase/outcome data, external records, test fitting, test predictions, final235 refit, submission or model promotion.
