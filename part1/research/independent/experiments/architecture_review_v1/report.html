Concrete directions for the next architecture/feature round

Structured eligibility and disease representation

Prior features treated criteria as whole-document word/character TF-IDF and ICD codes as generic text. ICD strings contain nested lists and dotted codes; generic tokenization separates decimal suffixes. No explicit inclusion/exclusion feature extractor was found in the phase scripts.

Build separate inclusion/exclusion text views, validated eligibility-burden features, and correctly parsed ICD code sets with parent categories. Keep unsupported clinical-bound extraction out until reviewed.

Compare each view alone and added to the fixed reason-embedding model, using fold-local vocabulary/scaling and the common grouped CV. Reject a block without repeatable gain.

Separate models for reason embeddings and structured metadata

Trees were tested mainly on raw/PCA reason coordinates; tree students and fixed-weight metadata co-training were also tried. The PDF says reason embeddings are randomly rotated, so coordinate splits have no inherent semantic meaning. Drug metadata are missing for a substantial fraction of trials.

Keep a rotation-tolerant embedding classifier; train regularized linear and shallow tree models on the new structured metadata. Evaluate metadata signal independently before any combination. If useful, test a strongly regularized gate learned from inner-fold predictions and explicit metadata coverage, rather than another global weight sweep.

Use exact matched embedding-only, metadata-only and combined controls. Fit any gate only within outer-training data. This direction is not a claim that metadata will help.

Joint multilabel prediction from representations

Powerset models, one classifier-chain recipe, and score-level joint decoders already exist. Repeating their names would not constitute a new architecture.

Only reopen joint modeling if the persistent-error review shows recurring co-occurrence mistakes. Compare a regularized joint label-set estimator on the new representations with independent heads, retaining an escape route for rare/unseen combinations. Prior semisupervised Gaussian mixtures and sparse prototypes should be controls, not advertised as untried methods.

Use the unchanged sample-F1 target, per-label diagnostics, and nested decoder selection. Advance based on both common CV pools before validation.
