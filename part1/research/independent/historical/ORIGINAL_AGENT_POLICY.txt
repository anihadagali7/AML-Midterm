# Part 1 evaluation convention

For new Part 1 model comparisons, use `benchmark_cv.py` and the frozen
`experiments/benchmark_v1/protocol.json`. Use the same saved grouped five-fold
assignments and three seeds for every candidate. Do not replace these seeds or
report a more favorable historical split as the primary comparison score.

Register a frozen recipe with a unique name, config, and decision rule. Fit all
preprocessing, pseudo-labeling, and any adaptive tuning inside each outer fold;
exclude held-out embedding groups and matching masked duplicates. The main
benchmark is inductive: validation/test inputs must not enter fitting.

Use CV to shortlist recipes before additional validation evaluations. Report
the common CV mean, repeat standard deviation, paired difference from the fixed
incumbent, and separate validation F1. Reuse existing validation measurements
with provenance when the recipe is unchanged. Keep failed trials and historical
scores. Chronological checks are supplementary, with separate labels.

Fixed CV is a development benchmark, not an untouched test. Repeated search can
overfit these folds, and earlier validation reuse is not undone by freezing them.

Preserve the user's constraints: no deep learning, external trial data/labels,
ID predictors, or reverse engineering of test labels. Preserve all original gold
labels. The final train-plus-validation refit remains deferred until the user
requests it. Keep the current submission unless a replacement is supported by
the evidence; this benchmark does not automatically promote models.

The user has additionally authorized a separate pooled train-plus-validation CV
comparison of frozen recipes. Use `benchmark_pooled_cv.py` and
`experiments/pooled_benchmark_v1/protocol.json` for that supplementary check.
Original validation labels may train a pooled fold only when those rows belong
to its training portion. This does not authorize a final all-label refit or test
input fitting. Keep the original training-only benchmark and original model's
validation result clearly distinguished from pooled CV.
